# HOOKKADR Mobile

Flutter / Dart application for Android and iOS.

Run: `flutter pub get` then `flutter run`.
Verify: `flutter analyze` and `flutter test`.

The app includes project editing, timeline operations and on-device MP4 export.
KART AI's first local workflow compiles advertising briefs into structured
storyboards and editable plans, verifies exports, and runs an original trained
technical-frame-quality model offline.

See [KART implementation and limits](docs/KART_AI_IMPLEMENTATION.md) and
[local model training/inference](ai/README.md) for actual capabilities,
evaluation evidence, reproducible commands and the remaining roadmap.
Store distribution requires release signing configuration.
