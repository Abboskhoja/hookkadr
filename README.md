# HOOKKADR Mobile

Flutter / Dart application for Android and iOS.

Run: `flutter pub get` then `flutter run`.
Verify: `flutter analyze` and `flutter test`.

Initial foundation: Create, Director, Studio, Assets and Projects navigation,
project creation, aspect ratio selection, opening and deleting projects.
Projects are currently session-local and are lost on restart.
AI generation, media import, timeline editing, export, authentication,
cloud persistence and billing are not implemented yet.
Store distribution requires release signing configuration.
